# Laravel LLM Router

![Laravel LLM Router fallback paths](art/banner.png)

Route Laravel AI requests through ordered provider/model chains with retries,
fallbacks, and tenant-aware overrides.

[![Tests](https://github.com/eloquage/laravel-llm-router/actions/workflows/run-tests.yml/badge.svg)](https://github.com/eloquage/laravel-llm-router/actions/workflows/run-tests.yml)
[![Latest Version](https://img.shields.io/packagist/v/illuma-law/laravel-llm-router)](https://packagist.org/packages/illuma-law/laravel-llm-router)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Requires PHP 8.3+ and Laravel 11, 12, or 13. Install Laravel AI and configure
its provider credentials to use the built-in `prompt()` method. You can use
the router without Laravel AI by providing your own request closure.

## Install

```bash
composer require illuma-law/laravel-llm-router
php artisan vendor:publish --tag=llm-router-config
```

For the built-in prompt integration:

```bash
composer require laravel/ai
```

Edit `config/llm-router.php` to set the provider/model order for each tier.

## Route a request

Use a closure to run each provider/model attempt. The router returns the result
and the provider/model that succeeded:

```php
use IllumaLaw\LlmRouter\Enums\DefaultTier;
use IllumaLaw\LlmRouter\Facades\LLMRouter;
use Laravel\Ai\Facades\Ai;

$response = LLMRouter::tier(DefaultTier::Large)
    ->run(fn (string $provider, string $model) => Ai::provider($provider)
        ->model($model)
        ->prompt('Summarize this report.'));

$answer = $response['result']->text;
$usedProvider = $response['provider'];
```

To pass a Laravel AI agent, provide its class name to `forAgent()` and the
instance to `agent()`:

```php
$response = LLMRouter::forAgent($agent::class)
    ->agent($agent)
    ->tier(DefaultTier::Large)
    ->run(fn (string $provider, string $model) => $agent->prompt(
        'Review this report.',
        provider: $provider,
        model: $model,
    ));
```

## Tenant and operation routing

Use `forTenant()` to apply the configured priority model when your resolver
marks that tenant as requiring it. Use `operation()` for a chain defined under
`operations` in the config:

```php
LLMRouter::resolvePriorityUsing(
    fn ($tenant): bool => $tenant->requires_local_models,
);

$response = LLMRouter::operation('image_generation')
    ->forTenant($tenant)
    ->run(fn (string $provider, string $model) => "Generated by {$provider}/{$model}");
```

Other reusable services include `ProviderAvailability`, `ChainRowValidator`,
and `CooldownStore`.
